# Angel Avila - Portfolio Page

## Overview
This portfolio website showcases my background, technical skills, and development projects as an aspiring web developer. It features responsive design elements, a dynamic modal greeting, session-based storage state handling, dark mode persistence via `localStorage`, and programmatic DOM rendering.

## Languages and Technologies
* **HTML5**: Semantic document structure and layout.
* **CSS3**: Custom styling, flexbox layouts, animations, and dark mode theme overrides.
* **JavaScript (ES6+)**: DOM manipulation, event handling, array loops, conditional display logic, object structures, and browser storage (`sessionStorage` and `localStorage`).

## Dependencies
* No external libraries or frameworks are required. Vanilla HTML, CSS, and modern JavaScript run natively in any modern web browser.

## How to Run
1. Clone or download the repository to your local machine.
2. Open the `index.html` file in any modern web browser (such as Google Chrome, Firefox, or Microsoft Edge).
3. Alternatively, publish the repository via GitHub Pages to view the live deployment.
